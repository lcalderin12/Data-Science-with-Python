# Data-Science-with-Python
This repository contains Python code and exercises developed as part of **OPIM 5512: Data Science with Python**. Its purpose is to apply the core principles of machine learning through hands-on programming, data analysis, model development, and evaluation.

## About This Repository

The work in this repository is intended to build practical experience with the data science workflow, including:

- Preparing, cleaning, and exploring data
- Creating meaningful features for analysis
- Applying supervised and unsupervised machine-learning methods
- Training, testing, and evaluating predictive models
- Interpreting results and communicating data-driven insights

## Tools and Technologies

The coursework primarily uses Python and common data science libraries such as:

- NumPy
- pandas
- Matplotlib and Seaborn
- scikit-learn
- Jupyter Notebook

## Purpose

This repository serves as a learning portfolio and a practical environment for executing code, testing machine-learning concepts, and strengthening problem-solving skills with real-world data. It documents my progress in applying the concepts taught in OPIM 5512 and developing a strong foundation in Python-based data science.
